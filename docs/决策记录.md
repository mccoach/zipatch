# 决策记录

## ADR-001：来源完整元信息预扫描与一次树形选择

日期：2026-11-26。
状态：用户已批准契约；实现已交付，待应用和实际验证。

### 背景

用户反馈目录合并含多个链接时，现有来源流程逐个弹窗，每次只决定一项。
原规则要求首次跟随链接前逐项授权，因此不能在第一次窗口列出尚未进入的下游链接。

### 决策

扫描、合并允许在最终选择前沿各层链接预扫描目录元信息，
包括根外目录；普通文件正文不在预扫描期间读取。
全部预扫描完成后一次树形选择。

取消父路线取消全部下游；启用子路线启用祖先；
重新启用父路线默认启用整个子树。
不同名义入口独立选择，同一实际目录名称快照在本次任务内共享。

选择交互前后复核固定现场，变化停止。
所选来源复用原预扫描计划，不再次枚举接受新范围。
缓存和选择不跨任务保存。

### 取舍及理由

采用一次完整预扫描，而非分批确认，满足用户集中决策和直观层级要求。
代价是最终未选分支也可能已被元信息访问，不能把取消说成从未访问。
网络目录或大量最终未选分支可能增加耗时，不能宣称必然提速。

普通文件正文仍在最终选择后获取，保持所选正文、来源隔离、
固定对象复核和唯一成果发布要求。
后台检查仍在首个链接停止，没有沿目标预扫描的许可。

### 边界

只替换扫描、合并来源的旧逐节点先行确认政策。
不改变指定链接入口操作、修改包、代码拆分、正式保护、
备份恢复或自动回滚的授权和失败政策。
排除文件夹不进入，循环、悬空、访问错误及输出冲突仍明确拒绝。
