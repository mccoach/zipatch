# 决策记录

## ADR-001：来源完整元信息预扫描与一次树形选择

日期：2026-11-26。
状态：用户已批准契约；实现已交付，待应用和实际验证。

### 背景

用户反馈目录合并含多个链接时，现有来源流程逐个弹窗，每次只决定一项。
原规则要求首次跟随链接前逐项授权，因此不能在第一次窗口列出尚未进入的下游链接。

### 决策

扫描、合并允许在最终选择前沿各层链接预扫描目录元信息，
包括根外目录；普通文件正文不在预扫描期间读取。
全部预扫描完成后一次树形选择。

取消父路线取消全部下游；启用子路线启用祖先；
重新启用父路线默认启用整个子树。
不同名义入口独立选择，同一实际目录名称快照在本次任务内共享。

选择交互前后复核固定现场，变化停止。
所选来源复用原预扫描计划，不再次枚举接受新范围。
缓存和选择不跨任务保存。

### 取舍及理由

采用一次完整预扫描，而非分批确认，满足用户集中决策和直观层级要求。
代价是最终未选分支也可能已被元信息访问，不能把取消说成从未访问。
网络目录或大量最终未选分支可能增加耗时，不能宣称必然提速。

普通文件正文仍在最终选择后获取，保持所选正文、来源隔离、
固定对象复核和唯一成果发布要求。
后台检查仍在首个链接停止，没有沿目标预扫描的许可。

### 边界

只替换扫描、合并来源的旧逐节点先行确认政策。
不改变指定链接入口操作、修改包、代码拆分、正式保护、
备份恢复或自动回滚的授权和失败政策。
排除文件夹不进入，循环、悬空、访问错误及输出冲突仍明确拒绝。

## ADR-002：去重保留正式路径及修改包整包执行授权

状态：用户已批准；本批正文引用实现已交付，待应用和验证。
授权扩充及修改包执行授权改造尚未交付，不登记为已完成。

### 决策

合并去重只省略重复正文，不丢失已保留名义文件路径。
首次记录保存正文，其他路径保存本层正文引用编号，
没有空正文及代码开始／结束行。
拆分从容器内解析完整正文，按各自名义路径执行既有实体写入政策，
不建立硬链接拓扑，不从磁盘补读被引用项。

扫描、合并继续一次完整元信息预扫描及逐项链接选择，
新增文件硬链接事实与展示。
修改包撤销授权裁剪：仅预演不弹执行授权窗口；
完整预演通过并展示确认后，涉及链接时一次整包同意或拒绝。
预演允许读取必要正文，执行授权不再作为预演读取许可。
拆分、主动备份还原扩充目标硬链接风险及任务范围内共享正文共同决定。
完整恢复树仍作为一个恢复对象，不执行树内子集。
不做任务范围外反向引用或全部硬链接名称扫描，不扩展.lnk。

### 验收补充

用户在本次需求讨论中确认：此前真实双卷及人工业务闭环已完成并通过，
此前链接处理功能按该用户补充确认登记为已验收。
未提供具体新增日志、测试数量或实施日期，不补造这些证据。
该结论不包括本次新授权政策及正文引用功能。
助手没有独立执行本机测试或人工验收。

别名回归和真实硬链接合并至实体拆分测试一并交付。
拆分直接消费解析后的普通文件正文，不另建磁盘引用读取链。
