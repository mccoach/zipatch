# 来源预扫描与授权

## 1. 适用范围与权限

适用于路径扫描及目录、文件列表、组合合并。
不改变修改包、代码拆分、备份原状态恢复或自动回滚。

启动正式来源任务允许沿链接访问目录元信息，包括根外目录和网络共享。
预扫描取得名称、类型、可靠对象身份、链接原定义及必要目录属性；
不打开普通文件读取正文。排除文件夹不进入，排除文件不取得合并正文。

最终选择只决定后续正文获取和成果范围。
未选分支可能已被预扫描；取消不能撤销此前目录访问。
后台列表检查没有预扫描许可，在首个链接处返回待授权。

循环、悬空目标、未知重解析点、访问故障及输出冲突停止任务，
不以选择部分项目掩盖不完整预扫描。

## 2. 唯一业务链

来源规则准备
→ 普通目录及链接目标元信息预扫描
→ 固定全部名义路线
→ 复核展示快照
→ 一次树形选择
→ 复核交互后的固定现场
→ 裁剪原计划
→ 所选正文首次获取或扫描元信息输出
→ 原来源复核、完整暂存及唯一成果发布。

文件硬链接、文件软链接、目录软链接及Junction均生成链接节点。
硬链接从可靠文件观察取得身份和链接数量，没有独立指向定义。
普通来源没有链接节点时静默保留。
全部链接未选不等于取消，允许生成只含忽略说明的成果；
普通来源仍按原规则保留。

## 3. 层级选择

软链接节点由实际入口与名义断点共同定位。
硬链接节点对应本次名义文件入口及实际文件元信息；
同对象不同名义路线分别选择，选择前后复核链接数量与身份。
父关系表示访问该节点实际经过的上一个链接，不按最终目标路径推测。

- 取消父节点：取消全部后代。
- 启用子节点：启用其全部祖先。
- 启用父节点：启用整个子树。
- 不同名义入口分别选择，即使实际目标相同。
- 同一文件仍可经其他保留路线输出，不因一个别名取消而全部取消。
- 未选分支在遗漏说明只列最外层取消节点。

窗口返回完整authorize/skip元组。
服务验证父先子后的固定关系，拒绝子项启用但父项未选的矛盾结果。
窗口不拥有目录扫描、正文获取、缓存或成果发布职责。

## 4. 事实与缓存归属

SourceTraversal拥有本次节点、父关系、名义路线及来源访问事实。
SourceEnumeration拥有本次实际目录名称快照及懒获取属性。
业务来源计划保留规则顺序、名义位置、源根换行语义和排除结果。

同一实际目录的名称只枚举一次；别名和多条规则复用该快照。
选择结束直接过滤原计划，不再次枚举选择文件。
正文仍按实际文件对象去重，只为最终所选来源取得一次。
不同已保留名义文件路径均进入正式成果；首次记录保存正文，
其他路径使用正文引用记录，不因去重丢失可拆分文件名称。

缓存不跨任务或重启保存，不是未来授权或免检查凭据。
选择前后按固定身份及目录结构时间比较预扫描快照，
不重读变化后的链接定义，不重新扫描接受新成员。
后续文件摘要及发布前来源复核继续使用原正式核心。

预扫描可能增加最终未选目录的访问成本。
名称复用减少重复枚举，不构成整体业务提速保证。

## 5. 生命周期与失败

SourceTraversal依次为collecting、selecting、selected；
选择取消、复核错误或决定非法进入failed。
选择开始后不再允许新增探查或再次选择。
失败或取消不读取后续正文、不发布成果；需要启动新任务。

扫描全程不读取普通文件正文。
合并正文读取失败、时间缺失、换行、输出隔离和发布故障，
继续按原业务契约分别处理。

## 7. 合并正文引用与实体拆分

同一实际文件对象的不同已保留名义路径，各自保留连续节号和主路径。
第一次成功记录保存真实正文，后续记录只增加
`ZIPATCH_CONTENT_REF:`及被引用的本层记录编号，
不输出代码开始行、代码结束行、空正文、重复来源说明或时间说明。

引用编号必须为规范正整数，只指向此前的真实普通文件正文记录。
不得引用其他引用记录、目录或链接结构记录，也不得跨层引用。
引用字段参与动态标识避撞。缺失、非法引用或截断容器整份拒绝。

唯一解析器在完整容器内取得引用正文，交付完整普通文件记录。
拆分以本项主路径定位并应用本项目标政策，不读取引用目标磁盘路径，
不依赖被引用项是否实际写入，也不创建硬链接。
缺失目标建立独立普通文件；目标已有链接时继续遵守现有授权和写回政策。

普通空文件仍具有真实代码开始和结束行，不能与正文引用混同。
排除、未授权和正文失败项仍只列遗漏名单，不生成引用占位。
正文获取失败在本次同对象范围内复用失败事实，不借别名重复尝试读取。

汇总分别表达实际存储正文文件数、正文引用记录数和成功名义文件记录总数。
同对象不同路线的换行成果冲突继续拒绝，来源与输出隔离、
全部使用路线复核以及成功正文摘要复核保持。
