## 正式链路

控件草稿
→ 物理行及稳定规则身份

→ 单后台任务进行文件选择
→ 界面核验版本和取消状态
→ 内存计算完整重复关系

→ 锁定相关输入

→ 保存规则表达
→ 保存或执行结束恢复输入。

执行直接消费最终检查的有序去重清单。

## 规则

- 删除全部半角双引号，不删除首尾空白。
- 删除引号后为空的行忽略。
- 删除引号后第一个字符为 | 才停用。
- 停用正文不检查、不去重。
- 分号是普通名称字符。
- 不展开环境变量或 ~。
- 支持盘符绝对路径、完整 UNC、源文件夹相对路径。
- 盘符相对路径、设备路径、单个根分隔符不支持。
- 相对规则禁止 ..，不使用当前工作目录作为隐含基准。
- *、? 不跨目录；** 必须独占路径段。
- 普通目录不展开；通配符只交付文件。
- 访问失败不能作为正常零命中。
- 配置和收藏保留表达，不保存通配符展开文件清单。

## 快照与调度

- 防抖为 200 毫秒。
- 一个运行任务，一个最新待检查请求。
- 正文变化或已接受源基准变化立即通知旧任务取消。
- 不等待旧线程退出，不强杀线程。
- 后台不访问 Tk。
- 使用规则身份及正文关联匹配结果，不按旧行号盲目回填。
- 重复关系只用内存匹配结果计算。
- 前序未确定时撤销后序绿色／黄色结论。
- 取消检查覆盖规则、目录枚举、目录项、属性及结果交付。
- 目录枚举器始终关闭。
- 取消任务不返回部分结果。
- 不轮询文件系统；界面的定时回调只检查后台任务完成状态。

## 保存与执行

允许最终检查后保存红项，并明确提示不能执行。
