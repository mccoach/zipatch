## 三、状态说明

| 状态 | 意义 |
|---|---|
| UNCHANGED | 当前内容已持久化，无需写入 |
| SAVED | 原子写入成功 |
| FAILED | 保存失败，成功快照不前移 |
| QUEUED | batch 内部排队，不代表最终成功 |
| DEFERRED | 普通请求无需写盘，但会话字段仍主动延后 |

persisted 仅对 UNCHANGED / SAVED 成立。
request_satisfied 允许普通操作接受 DEFERRED。
业务前置、草稿明确保存和退出使用 include_session=True。

## 四、异常 batch 使用约束

batch 仅用于短同步保存阶段，不覆盖原生选择、确认、wait_window 或业务执行。

batch 不自动回滚。
异常后必须先调用 recover_aborted_batch，明确放弃本次半完成变化。
恢复只涉及本批次经 accept 修改过的字段，不复制整份配置。
恢复前继续 accept 或 save 会抛出 RuntimeError。

生产操作优先先准备最终值，再一次接受，不为使用 batch 而增加批次。
